# Tech Rules

This directory contains project-level technical rules that guide how the system
writes, structures, formats, and organizes code. These rules apply to all
profiles that implement code or validate technical output.

## Purpose
- Define language- and framework-specific conventions
- Establish formatting, naming, and structural patterns
- Document code organization rules and directory layout
- Capture technical invariants that must be followed across the project
- Provide reference material for profiles that implement or validate code

## Scope
Files in this directory describe **how code should be written**, including:
- Naming conventions
- File and folder structure
- Formatting rules
- Schema and type patterns
- Domain structure and boundaries
- Anti-patterns and prohibited structures
